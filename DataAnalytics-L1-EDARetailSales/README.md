# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project analyzes retail sales data using Python to identify sales trends, customer purchasing patterns, and product category performance.

## Dataset
- Total transactions: 1,000
- Features: 10
- Missing values: 0
- Duplicate records: 0

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Dataset inspection
2. Descriptive statistical analysis
3. Monthly sales trend
4. Quarterly sales trend
5. Customer age group distribution
6. Gender distribution
7. Revenue by product category
8. Correlation heatmap
9. Average sales by gender

## Key Insights
- The 46–60 age group had the highest number of customers.
- Electronics generated the highest category revenue.
- Q4 2023 recorded the highest quarterly sales.
- Average spending was almost equal across genders.

## Business Recommendations
1. Target the 46–60 age group with suitable promotions.
2. Maintain sufficient inventory for Electronics and Clothing.
3. Introduce seasonal campaigns during slower sales periods.

## Limitation
Individual product names were unavailable, so a top 10 individual-product analysis could not be performed.
